# Amazon Quarterly Sales Analysis | Interactive Excel Dashboard

## Project Overview

This project focuses on analyzing Amazon sales transaction data using Microsoft Excel to evaluate sales performance, customer purchasing behavior, order distribution, payment preferences, and geographical sales trends.

An interactive quarterly sales dashboard was developed using Excel Pivot Tables, Pivot Charts, and Slicers to convert raw sales data into meaningful business insights.

The dashboard helps understand customer segmentation, identify top-performing states, analyze order statuses, and compare different payment methods.

## Project Objectives

- Analyze sales distribution between male and female customers.
- Identify the top 10 states based on sales amount.
- Evaluate order status, including Delivered, Refunded, and RTO.
- Analyze sales performance across different payment methods.
- Compare payment preferences by customer gender.
- Build an interactive dashboard for better sales monitoring and decision-making.

## Project Workflow

### Step 1: Data Collection
Imported the Amazon sales dataset into Microsoft Excel for analysis.

### Step 2: Data Cleaning and Preparation
- Checked the dataset for missing and inconsistent values.
- Reviewed duplicate and unnecessary columns.
- Standardized column names and formatting.
- Checked date, quantity, and invoice amount formats.
- Prepared the dataset for further analysis.

### Step 3: Data Analysis
Used Excel Pivot Tables to summarize and analyze sales data across different business dimensions:

- Customer gender
- Shipping states
- Order status
- Payment methods
- Sales amount
- Order ID count

### Step 4: Dashboard Development
Created an interactive dashboard using Pivot Charts and Slicers.

The dashboard includes:

1. **Sales by Gender:** Pie chart comparing invoice amounts generated by female and male customers.
2. **Top 10 States Sales:** Horizontal bar chart showing state-wise sales performance.
3. **Order Status Analysis:** Pie chart displaying the percentage distribution of Delivered, Refunded, and RTO orders.
4. **Payment Method Analysis:** Column chart comparing payment methods based on invoice amount and customer gender.
5. **Orders by Payment Method:** Doughnut chart showing order distribution across different payment methods.
6. **Interactive Slicers:** Added filters for payment method, shipping state, and customer gender to explore the data dynamically.

### Step 5: Insights and Interpretation

The dashboard highlights the following observations:

- Female customers contribute approximately 66% of the invoice amount, compared with 34% from male customers.
- Delivered orders represent approximately 55% of the displayed order-status distribution.
- Refunded orders account for approximately 32%, while RTO orders represent 13%.
- State-wise sales analysis helps identify the leading sales regions.
- Payment-method analysis provides an overview of customer payment preferences.
- Interactive filters allow users to explore sales performance across different states, genders, and payment methods.
